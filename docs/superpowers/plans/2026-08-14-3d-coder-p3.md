# 3D-Coder P3 — Print Lane Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take a gated mesh to a verified, multi-colour `.gcode.3mf` on a USB stick: slice with Bambu Studio for the X2D, map anatomy structures to AMS slots, enforce the Print Gate, show the plate/layers/stats in the Print View, and write the job to removable media with a hash check.

**Architecture:** A fourth uv/FastMCP server, `print-mcp`, drives the Bambu Studio CLI headlessly, parses the sliced archive's `Metadata/slice_info.config` for the stats, decimates `Metadata/plate_N.gcode` into a compact per-layer polyline JSON the renderer can draw cheaply, gates the result, and copies it to a removable drive. The Print View becomes the third live panel mode.

**Tech Stack:** Python 3.12 + uv + FastMCP; Bambu Studio CLI (user-installed); trimesh (plate fit), stdlib zipfile/xml/hashlib; renderer: SolidJS + the existing three.js viewer.

**Spec:** `3D-Coder/docs/superpowers/specs/2026-08-13-3d-coder-design.md` — §3.3 Print View, §4.4 print-mcp (**amended 2026-08-14: USB-only delivery, no LAN/MQTT**), §5.3 Print Gate, §7 P3.

## Global Constraints

- **Delivery is USB only.** The lab X2D is not networked. No FTPS, no MQTT, no `send_to_printer`. The lane ends at a verified file on a removable drive.
- **PREREQUISITE (user action): install Bambu Studio** (latest, so it carries X2D profiles) from <https://bambulab.com/en/download/studio>. Task 1 discovers the binary and profiles and fails loudly with instructions if absent.
- **AMENDED 2026-08-14 after hands-on verification — the documented preset path does not work.** `--load-settings` with exported preset JSON returns `"The input preset file is invalid and can not be parsed"` (rc −5), and composing `project_settings.config` from the shipped system profiles **crashes** the slicer (0xC0000005): those profiles store per-variant ARRAYS the GUI resolves down to the chosen printer variant (66 keys arrive as 6-element lists, `name` becomes a list). Reimplementing that resolution is guesswork, and a subtly wrong machine definition slices a plausible file that ruins a print. **What works: hand the CLI a complete project authored by Bambu Studio.** The lab exports one template project per material/process from the GUI; `project.build_from_template` swaps our mesh into its single object and leaves the operator's print profile untouched. Verified end to end: the demo rack slices `return_code 0`, 67 min, 41.97 g. **`result.json`, written into the working directory, is the CLI's real report channel** — richer than `slice_info.config` (per-feature times, per-filament grams, object bbox, warnings, `upward_compatible_machine`) — and it is the only way to see errors, since the GUI-subsystem binary writes nothing to a captured stdout.
- Remaining CLI ground truth (verified 2026-08-14 from the [Bambu wiki](https://github.com/bambulab/BambuStudio/wiki/Command-Line-Usage) and [Printago's reference](https://printago.io/blog/bambu-studio-cli-reference)):
  `bambu-studio --slice <plate> --load-settings "machine.json;process.json" --load-filaments "f1.json;f2.json" --allow-newer-file --export-3mf <out.gcode.3mf> <model>`; profiles must be **exported JSON files, not preset names**; output is a zip whose bare gcode lives at `Metadata/plate_N.gcode`; `--skip-useless-pick` speeds batches; `--mstpp <seconds>` bounds a runaway slice; slicing leaves **hundreds of MB of temp files in the working directory** — always run in a temp sandbox and delete it.
- Stats come from `Metadata/slice_info.config` (XML): `prediction` (seconds), `weight` (g), and per-slot `used_m`/`used_g`/`type`/`color`/`tray_info_idx`, plus `support_used`, `nozzle_diameters`, `printer_model_id`. **Filament ids are 1-based** (`id="1"` is logical slot 0).
- X2D build volume **256×256×260 mm** (235.5×256×256 in dual-nozzle mode) — the plate-fit check uses the dual-nozzle figure whenever the aux nozzle is in play.
- Machine-owned paths keep their walls: `provenance.json`, `meshes/qa/`, and now `prints/qa/` are edit-denied in `3dcoder-config/opencode.jsonc` AND `claude-mcp` `DENY_TOOLS` AND `claude-chat-protocol.ts` `DENY_TOOLS` (three places now — a test on each side pins them together).
- Python: `uv run pytest` from the server dir. Renderer: `bun test src/components/coder3d/` and `bun run typecheck` from `packages/app` (never repo root).
- Main-process changes need an app restart (WMI + hidden-wscript launcher); renderer changes hot-reload.
- Commits: plain `-m`, no double-quotes in the message, Azam sole author, never any Claude attribution.

```python
"""Locate Bambu Studio and its X2D profiles.

Profiles must be handed to the CLI as exported JSON files — preset names alone
do not work — but the installer ships the system profiles as JSON under
resources/profiles/BBL, so a normal install needs no GUI export step.
"""
import os
from pathlib import Path

_CANDIDATES = [
    Path(r"C:\Program Files\Bambu Studio\bambu-studio.exe"),
    Path(r"C:\Program Files (x86)\Bambu Studio\bambu-studio.exe"),
    Path(os.environ.get("LOCALAPPDATA", "")) / "Programs" / "Bambu Studio" / "bambu-studio.exe",
]

INSTALL_HINT = (
    "Bambu Studio is required for slicing. Install the latest version from "
    "https://bambulab.com/en/download/studio (it ships the X2D profiles), then "
    "restart 3D-Coder. If it is installed somewhere unusual, set CODER3D_BAMBU_STUDIO "
    "to the full path of bambu-studio.exe."
)


class SlicerMissing(RuntimeError):
    def __init__(self):
        super().__init__(INSTALL_HINT)


class ProfilesMissing(RuntimeError):
    pass


def find_bambu_studio() -> Path | None:
    override = os.environ.get("CODER3D_BAMBU_STUDIO")
    if override:
        path = Path(override)
        return path if path.is_file() else None
    for candidate in _CANDIDATES:
        if candidate.is_file():
            return candidate
    return None


def _pick(files: list[Path], *needles: str) -> Path | None:
    for needle in needles:
        for f in files:
            if needle.lower() in f.name.lower():
                return f
    return None


def find_x2d_profiles(root: Path) -> dict:
    """root = the Bambu Studio install directory."""
    base = Path(root) / "resources" / "profiles" / "BBL"
    machines = sorted((base / "machine").glob("*.json")) if (base / "machine").is_dir() else []
    processes = sorted((base / "process").glob("*.json")) if (base / "process").is_dir() else []
    filaments = sorted((base / "filament").glob("*.json")) if (base / "filament").is_dir() else []
    machine = _pick(machines, "X2D")
    if machine is None:
        raise ProfilesMissing(
            "No X2D machine profile found in this Bambu Studio install. Update Bambu Studio "
            "to a version that supports the X2D, or export an X2D profile from the GUI and "
            "point CODER3D_X2D_MACHINE_PROFILE at it."
        )
    process = _pick(processes, "X2D", "0.20mm Standard") or (processes[0] if processes else None)
    if process is None:
        raise ProfilesMissing("No process profile found in this Bambu Studio install.")
    return {"machine": machine, "process": process, "filaments": filaments}
```

```python
import shutil
import subprocess
import tempfile


def build_slice_args(model, out_3mf, profiles, plate: int = 1, timeout_s: int = 1800,
                     extra: list[str] | None = None) -> list[str]:
    args = [
        "--slice", str(plate),
        "--load-settings", f"{profiles['machine']};{profiles['process']}",
    ]
    filaments = profiles.get("filaments") or []
    if filaments:
        args += ["--load-filaments", ";".join(str(f) for f in filaments)]
    args += [
        "--allow-newer-file",
        "--skip-useless-pick",
        "--mstpp", str(timeout_s),
        "--export-3mf", str(out_3mf),
    ]
    if extra:
        args += extra
    args.append(str(model))
    return args


def slice_model(model, out_dir, profiles, filaments=None, timeout_s: int = 1800) -> dict:
    binary = find_bambu_studio()
    if binary is None:
        raise SlicerMissing()
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    out_3mf = out_dir / (Path(model).stem + ".gcode.3mf")
    used = {**profiles, "filaments": filaments if filaments is not None else profiles.get("filaments", [])}
    # A slice drops hundreds of MB of temp files in the working directory, so it
    # runs in a sandbox we delete afterwards.
    sandbox = Path(tempfile.mkdtemp(prefix="coder3d-slice-"))
    try:
        proc = subprocess.run(
            [str(binary), *build_slice_args(Path(model), out_3mf, used, timeout_s=timeout_s)],
            cwd=sandbox, capture_output=True, text=True, encoding="utf-8",
            errors="replace", timeout=timeout_s + 120,
        )
        ok = out_3mf.is_file() and proc.returncode == 0
        return {
            "ok": ok, "output": str(out_3mf) if ok else "",
            "returncode": proc.returncode,
            "stdout_tail": proc.stdout[-4000:], "stderr_tail": proc.stderr[-4000:],
        }
    finally:
        shutil.rmtree(sandbox, ignore_errors=True)
```
